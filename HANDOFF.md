# Handoff

**Branch:** `main`. **Remote:** https://github.com/shmuhaisin/MIDAN (public).

## What exists
- `apps/web`: 7 public page types in 2 languages. Everything visible works; there is no backend connection, because nothing needs one yet.
- `apps/api`: `GET /v1/health` and Swagger at `/docs`. No database, auth or business logic.
- `services/ai`: `GET /health` and `midan_ai/foundation_graph.py`, which only proves LangGraph is wired (typed state, bounded loop, checkpoint). It is **not** Graph A or B, and its in-memory checkpointer must not be reused for them.

## Supabase
Project `al-midan-ya-hamidan`, ref `squpszwbrqkflezfltoj`, region `eu-central-1`, $0/month, empty. The unrelated project `ALNADA` in the same organization must not be touched.

The database password was generated by Supabase and isn't available to us. Prisma's `DATABASE_URL` needs it: the owner must reset it in the dashboard (Project Settings > Database) and put it in a local `.env`. Migrations can also be applied through the Supabase MCP tools.

## Tests that were run
- Web: type check, build, message parity tests (ar/en shape match).
- API: Jest health test, plus a real boot with `/v1/health` and `/docs` returning 200.
- AI: pytest, 2 passing.
- Browser: all 16 routes at 375px (no overflow, correct `dir`, no broken images); all four language and theme combinations on desktop; field explorer and level buttons; theme persistence.

## Not checked
- Not every page was inspected by eye in all four combinations; the home page was.
- No automated accessibility audit or end-to-end suite. Arabic copy has not been reviewed by a native editor.
